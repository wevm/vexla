# middleware [Returns Hono middleware that serves the flags path and scopes flags to each request]

`vexla/hono` exports `middleware` and its types. [Hono](/guides/hono) shows the full setup.

```ts [app.ts]
import { type Env, middleware } from 'vexla/hono'
import { Hono } from 'hono'
import { vexla } from './flags.js'

const app = new Hono<Env<typeof vexla>>()

// Serves /.flags, and sets flags and c.var.flags for every other request.
app.use(middleware(vexla))

app.get('/pricing', async (c) => c.json({ pricing: await c.var.flags.get('PRICING') }))
```

## Signature

```ts
// Hono middleware for one instance
middleware(vexla: Vexla.Vexla): MiddlewareHandler<Env<typeof vexla>>
```

## Behavior

1. A request under `vexla.path` returns the response of `vexla.fetch`. The next handler does not run.
2. Other requests set `c.var.flags`, then run the next handler in `Values.run`, so `flags` holds the values of the request.
3. If the request has `flag.*` search parameters, the response receives the `vexla` cookie.

## c.var.flags

| Property   | Type                      | Behavior                         |
| ---------- | ------------------------- | -------------------------------- |
| `evaluate` | `() => Promise<Values>`   | `vexla.evaluate` for the request |
| `get`      | `(key) => Promise<Value>` | `vexla.get` for the request      |
| `script`   | `() => Promise<string>`   | `vexla.script` for the request   |

## Types

- **`Env<vexla>`:** the Hono environment that the middleware sets, `{ Variables: { flags: Flags<vexla> } }`.
- **`Flags<vexla>`:** the type of `c.var.flags`.
