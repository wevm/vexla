# vexla/server [The Vexla instance, stores, the dev route, and the admin API]

`vexla/server` evaluates runtime flags and serves the flags path. It has no dependencies and no Node built-ins, so it runs in Node, Bun, Deno, and edge runtimes.

```ts [flags.ts]
import { Vexla, Store } from 'vexla/server'
import { definitions } from './vexla.gen.js'

// One instance for each application instance. It listens on no port.
export const vexla = Vexla.create({
  definitions,
  secret: process.env.VEXLA_SECRET,
  store: Store.memory(),
})
```
