# flargs/server [The Flargs instance, stores, the dev route, and the admin API]

`flargs/server` evaluates runtime flags and serves the flags path. It has no dependencies and no Node built-ins, so it runs in Node, Bun, Deno, and edge runtimes.

```ts [flags.ts]
import { Flargs, Store } from 'flargs/server'
import { definitions } from './flargs.gen.js'

// One instance for each application instance. It listens on no port.
export const flargs = Flargs.create({
  definitions,
  secret: process.env.FLARGS_SECRET,
  store: Store.memory(),
})
```
