# Store.env [Returns a read-only store over FEATURE_* variables]

The store reads each value from the variable of its key. It holds no definitions and has no `keys` operation. A write throws `Store.ReadOnlyError`, so the value routes of the admin API fail.

```ts [flags.ts]
import { Flargs, Store } from 'flargs/server'
import { definitions } from './flargs.gen.js'

export const flargs = Flargs.create({
  definitions,
  secret: process.env.FLARGS_SECRET,
  // Values from variables with the APP_ prefix, such as APP_NEW_CHECKOUT.
  store: Store.env(process.env, { envPrefix: 'APP_' }),
})
```

## Signature

```ts
// A store that reads variables
Store.env(variables: Record<string, string | undefined>, options?: { envPrefix?: string }): Store
```

## Behavior

- **Variable names:** the key in `SCREAMING_SNAKE_CASE` after `envPrefix`, which defaults to `'FEATURE_'`. The `env` field of a declaration does not apply.
- **Text:** each value is text. The instance decodes it for the type of the flag.
- **Order:** a store value precedes `decide`, so a variable of this store precedes `decide`. A variable that the instance reads through `env` follows `decide`.

## Errors

| Error                 | Thrown when                 |
| --------------------- | --------------------------- |
| `Store.ReadOnlyError` | `set` or `delete` is called |
