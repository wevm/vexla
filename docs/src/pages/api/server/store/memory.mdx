# Store.memory [Returns a store in memory, for dev mode and tests]

The store holds values and definitions in the memory of the instance. A restart clears it. `vexla dev` uses it.

```ts [flags.ts]
import { Vexla, Store } from 'vexla/server'
import { definitions } from './vexla.gen.js'

export const vexla = Vexla.create({
  definitions,
  dev: true,
  // Starts with one store value.
  store: Store.memory({ values: { PRICING: 'b' } }),
})
```

## Signature

```ts
// A store with values, keys, and definitions
Store.memory(options?: { definitions?: Record<string, unknown>; values?: Record<string, Json> }): Store
```

## Options

- **`definitions`:** definitions to start with, in the format of a flags file.
- **`values`:** values to start with, keyed by flag key.

## Behavior

The store implements every operation, including `keys` and `definitions`. `definitions.delete` also deletes the value of the flag.
