# Values [Scopes the values of a request on the server, and loads the values of a page in a browser]

`Values` sets the source of [`flags`](/api/core/flags). On the server, `Values.run` scopes the values of one request with `AsyncLocalStorage`. In a browser, `Values.load` requests the public values from the values endpoint.

```ts [worker.ts]
import { Values } from 'vexla'
import { vexla } from './flags.js'
import { app } from './app.js'

export default {
  // Every read of flags inside app.fetch uses this request.
  fetch: (request: Request) => Values.run(vexla, request, () => app.fetch(request)),
}
```

## Values.run

```ts
// Evaluates every runtime flag for request, then runs fn with those values in flags
Values.run(vexla: { evaluate: (request: Request) => Promise<Record<string, unknown>> }, request: Request, fn: () => result): Promise<Awaited<result>>
```

- **Evaluation:** it evaluates every flag, so every `decide` runs once. A flag with an expensive `decide` uses `vexla.get` in place of `flags`.
- **Concurrency:** concurrent requests read their own values.
- **Runtimes:** Node, Bun, Deno, and Cloudflare Workers with `nodejs_compat`. It reaches `AsyncLocalStorage` through `process.getBuiltinModule`, so a browser bundle never imports `node:async_hooks`.
- **Errors:** throws an `Error` when the runtime has no `AsyncLocalStorage`.

## Values.load

```ts
// Requests GET <url>/values, and resolves with the values
Values.load(options?: { fetch?: typeof fetch; url?: string }): Promise<Record<string, Json>>
```

| Option  | Default            | Meaning                                  |
| ------- | ------------------ | ---------------------------------------- |
| `fetch` | `globalThis.fetch` | the fetch function                       |
| `url`   | `'/.flags'`        | the URL of the flags path, on any origin |

- **Page values:** the response replaces the values of the page, and each `Values.subscribe` listener runs.
- **Overrides:** it copies `flag.*` search parameters of the page to `sessionStorage`, and sends them with each request. `flag.reset` clears them. A signed override keeps its signature.
- **CORS:** a values endpoint on another origin needs `cors` on `Vexla.create`.
- **Errors:** throws an `Error` when the response status is not `2xx`.

## Values.subscribe

```ts
// Calls fn after each Values.load, and returns a function that removes fn
Values.subscribe(fn: () => void): () => void
```

`useFlag` of `vexla/react` uses it with `useSyncExternalStore`.

## Values.snapshot

```ts
// Returns the current values: the request scope, then the page, then the environment
Values.snapshot(): Record<string, Json>
```

## Types

- **`Snapshot`:** resolved values, keyed by flag key.
- **`Evaluator`:** the part of an instance that `Values.run` needs, `{ evaluate }`.
