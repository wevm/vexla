# Definitions [Parses .env.flags, decodes variables, and returns the manifest and the generated module]

`Definitions` holds the pure functions over flag definitions. The Flargs instance, the build plugins, and the CLI use the same functions.

```ts [definitions.ts]
import * as Fs from 'node:fs'
import { Definitions } from 'flargs'

// Parses .env.flags. Throws Definitions.InvalidDeclarationError on a bad declaration.
export const definitions = Definitions.parseFile(Fs.readFileSync('.env.flags', 'utf8'))
```

## Types

### Definition

One validated flag. `parse` fills `build` and `public`. The key of the flag is also the name of its environment variable.

| Property      | Type                                                      | Meaning                                               |
| ------------- | --------------------------------------------------------- | ----------------------------------------------------- |
| `build`       | `boolean`                                                 | `true` for a build flag                               |
| `default`     | `Json`                                                    | the value when no other source has one                |
| `description` | `string \| undefined`                                     | text for the dev route and the admin API              |
| `expires`     | `string \| undefined`                                     | the date (`YYYY-MM-DD`) after which the flag is stale |
| `options`     | `readonly string[] \| undefined`                          | the values of a select flag                           |
| `public`      | `boolean`                                                 | `true` when the value may reach a browser             |
| `type`        | `'boolean' \| 'json' \| 'number' \| 'select' \| 'string'` | the type of the value                                 |

### Other Types

- **`Definitions`:** every flag of a project, keyed by flag key, such as `NEW_CHECKOUT`.
- **`Json`:** a JSON value.
- **`Type`:** the union of the five flag types.
- **`Value<definition>`:** the value type of a definition: the options of a select flag, or the widened default of a JSON flag.
- **`Values<definitions>`:** the value types of definitions, keyed by flag key.
- **`Manifest`:** `{ flags: Definitions, version: 1 }`.
- **`Issue`:** a problem that `check` returns: `{ key, reason }`. `key` is the variable, and the key of a declared flag.

## Functions

### Definitions.parse

```ts
// Returns the definitions of a definition object, the format of the store and the admin API
Definitions.parse(input: unknown): Definitions
```

Each key is the name of the environment variable of its flag, such as `NEW_CHECKOUT`. Throws `InvalidDeclarationError` for a key that is not a variable name, an unknown field, a missing `type` or `default`, a default of the wrong type, invalid `options`, or an invalid `expires`.

### Definitions.parseFile

```ts
// Returns the definitions in the text of .env.flags
Definitions.parseFile(text: string): Definitions
```

Each variable declares a flag. Its name is the key, and its value is the default. The comment lines directly above it hold the description and the `@type`, `@public`, `@build`, and `@expires` tags. Without `@type`, the type is inferred from the default as `Definitions.infer` infers it. [Flags File](/guides/flags-file) describes each tag. Throws `InvalidDeclarationError` with the line number for an invalid line, an unknown type or tag, a flag declared twice, or an invalid default.

### Definitions.removeFromFile

```ts
// Returns the text of .env.flags without the declaration of one key
Definitions.removeFromFile(text: string, key: string): string
```

Removes the comment lines, the variable, and one blank line after it. Returns `text` unchanged when no variable declares `key`. [`flargs retire`](/cli/retire) uses it.

### Definitions.infer

```ts
// Returns the value that the text of an undeclared variable implies
Definitions.infer(raw: string): Json
```

`true` and `false` are a boolean, a number is a number, a JSON object or array is JSON, and other text is a string. Outside `Values.run`, `flags` reads each variable with this function.

### Definitions.check

```ts
// Returns the problems of an environment against the definitions
Definitions.check(definitions, env, options?: { now?: number; prefix?: string }): readonly Issue[]
```

| `reason`  | Condition                                                        |
| --------- | ---------------------------------------------------------------- |
| `invalid` | a value that is not a value of its flag                          |
| `stale`   | a flag past its `expires` date                                   |
| `unknown` | with `prefix`, a variable with that prefix that no flag declares |

`prefix` has no default, so without it, `check` reports no `unknown` issue. `FEATURE_` is a typical value.

### Definitions.decode

```ts
// Returns the value that the text of a variable or a search parameter holds
Definitions.decode(definition: Definition, raw: string, key: string): Json
```

Throws `InvalidValueError` when the text is not a value of the flag. The error names the key, which is also the variable, and never holds the text.

### Definitions.defines

```ts
// Returns define replacements for build flags, such as { 'flags.MAINTENANCE_BANNER': 'false' }
Definitions.defines(definitions, options?: { env?: Record<string, string | undefined>; identifier?: string; values?: Record<string, Json> }): Record<string, string>
```

Each value resolves from `values`, then the variable in `env`, then the default. `identifier` defaults to `'flags'`. A bundler `define` replaces a global `flags` object only, not a member of an imported binding. Code that imports `flags` uses `flargs/vite` or `flargs/zile`.

### Definitions.generate

```ts
// Returns the source of flargs.gen.ts
Definitions.generate(definitions, options?: { visibility?: 'all' | 'public' }): string
```

The module exports `definitions` as a constant and augments `Register`. `visibility: 'public'` declares public flags only.

### Definitions.manifest

```ts
// Returns { flags: definitions, version: 1 }
Definitions.manifest(definitions): Manifest
```

### Other Functions

| Function                      | Returns                                                                   |
| ----------------------------- | ------------------------------------------------------------------------- |
| `encode(value)`               | the text of a value in a variable or a search parameter                   |
| `validate(definition, value)` | `true` when the value is a value of the flag                              |
| `isStale(definition, now?)`   | `true` from the day after `expires`, in UTC                               |
| `values(definitions, env)`    | the values that `env` sets for declared flags. Throws `InvalidValueError` |
| `publicOf(definitions)`       | the definitions of public flags only                                      |

## Errors

| Error                                 | Thrown when                                                            |
| ------------------------------------- | ---------------------------------------------------------------------- |
| `Definitions.InvalidDeclarationError` | a declaration does not follow the schema. `key` names the flag         |
| `Definitions.InvalidValueError`       | a variable or an override holds an invalid value. `key` names the flag |
