# withFlags [Returns test options that set runtime flag values]

`vexla/vitest` exports `withFlags`, `setup`, the `Flags` type, and `BuildFlagError`. [Vitest](/guides/vitest) shows the full setup.

```ts [pricing.test.ts]
import { test } from 'vitest'
import { withFlags } from 'vexla/vitest'

// Runs with PRICING set to 'b'. The second argument holds the other options of the test.
test('shows the annual price', withFlags({ PRICING: 'b' }, { timeout: 10_000 }), async () => {})
```

## withFlags

```ts
// Options for test or describe of Vitest
withFlags(values: Flags, options?: SuiteOptions): SuiteOptions
```

`withFlags` returns `options` with `values` in `meta`. The setup file reads `meta` of the test and of each outer block.

1. The values of the outer block apply first, then the values of each inner block, then the values of the test. A later value takes precedence.
2. Before the test runs, each value is checked against the definitions.
3. The test runs in `Values.run`. The values of step 1 take precedence over the evaluated values.

## setup

```ts
// Registers the aroundEach hook. The setup file of the Vite plugin calls it.
setup(options: { aroundEach: typeof aroundEach; vexla: Vexla.Vexla }): void
```

| Option       | Type          | Behavior                                                  |
| ------------ | ------------- | --------------------------------------------------------- |
| `aroundEach` | `aroundEach`  | the `aroundEach` function of `vitest` or `vite-plus/test` |
| `vexla`      | `Vexla.Vexla` | evaluates every value that a test does not set            |

The setup file of the plugin uses `Vexla.create` in dev mode, with the definitions of the flags file and the variables of the flags. In browser mode, `setup` registers no hook, since a browser has no `AsyncLocalStorage`.

## Errors

| Error                           | Cause                                |
| ------------------------------- | ------------------------------------ |
| `Override.UnknownFlagError`     | no flag declares the key             |
| `Definitions.InvalidValueError` | the value is not a value of the flag |
| `BuildFlagError`                | the flag is a build flag             |

## Types

- **`Flags<definitions>`:** the runtime flag values that a test can set. Build flags are absent.
