# vexla [Returns the Vite plugin that generates types and replaces build flag reads]

`vexla/vite` exports the plugin as its default export. [Vite](/guides/vite) shows the setup.

```ts [vite.config.ts]
import vexla from 'vexla/vite'
import { defineConfig } from 'vite'

export default defineConfig({
  // Reads .env.flags and writes vexla.gen.ts at the Vite root.
  plugins: [vexla()],
})
```

## Signature

```ts
// The Vite plugin
vexla(options?: vexla.Options): Plugin
```

## Options

| Option  | Type                 | Default          | Meaning                                                      |
| ------- | -------------------- | ---------------- | ------------------------------------------------------------ |
| `out`   | `string`             | `'vexla.gen.ts'` | the generated module, relative to the Vite root              |
| `path`  | `string`             | `'.env.flags'`   | the flags file, relative to the Vite root                    |
| `store` | `Pick<Store, 'get'>` | none             | a store whose values precede the environment for build flags |

## Behavior

- **Generation:** at the start of a build, the plugin parses the flags file and writes the generated module when its content changes.
- **Values:** each build flag resolves from `store`, then its variable, then its default. Variables come from `process.env` and the `.env` files of the Vite mode.
- **Rewrite:** in each JavaScript or TypeScript module outside `node_modules`, a read of a build flag through the `flags` import of `vexla`, or `useFlag` of `vexla/react`, becomes a literal.
- **Private flags:** in browser code, a read of a private flag, build or runtime, fails the build. Server code (`ssr`) may read any flag.
- **Vitest:** in a Vitest run, the plugin adds a setup file that calls [`setup`](/api/vitest) of `vexla/vitest`. Each test runs in `Values.run`, and [`withFlags`](/api/vitest) sets values for a test or a block.
- **Dev server:** a change of the flags file writes the module again and triggers a full reload.
- **Dependency:** the rewrite uses the TypeScript compiler API, so `typescript` must be installed.
