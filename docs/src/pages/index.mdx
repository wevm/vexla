## Overview

The flags file declares each flag with its type and its default. A flag is private unless `public` is `true`.

```json [flags.json]
{
  "$schema": "./node_modules/flargs/schema.json",
  "newCheckout": { "default": false, "public": true, "type": "boolean" },
  "pricing": { "default": "a", "options": ["a", "b", "c"], "type": "select" }
}
```

Each flag links to one environment variable. The server reads the value for each request.

```ts [app.ts]
import { flags } from 'flargs'

// Typed from flargs.gen.ts. The read is synchronous and takes no request argument.
if (flags.newCheckout) renderNewCheckout()
```
