## Overview

The flags file, `.env.flags`, declares each flag with its type and its default. A flag is private unless it has the `@public` tag.

```sh [.env.flags]
# Use the new checkout flow.
# @type {boolean} @public
NEW_CHECKOUT=false

# Pricing page variant.
# @type {'a' | 'b' | 'c'}
PRICING=a
```

A flag reads the environment variable of the same name. A build flag resolves when the bundle builds, with no server. A runtime flag resolves on the server for each request.

```ts [app.ts]
import { flags } from 'vexla'

// Typed from vexla.gen.ts. The read is synchronous and takes no request argument.
if (flags.NEW_CHECKOUT) renderNewCheckout()
```
