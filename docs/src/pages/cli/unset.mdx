# unset [Deletes the store value of a flag]

`flargs unset` calls `DELETE /.flags/values/:key`, which needs `write` access. The flag then resolves from `decide`, its variable, or its default. The command also deletes the orphan value of a removed flag.

```sh
# Deletes the store value of PRICING
npx flargs unset PRICING
```

## Signature

```sh
# Arguments first, then options
flargs unset <key> [options]
```

## Arguments

### key

- **Type:** `string`

Key of the flag, such as `NEW_CHECKOUT`.

## Options

### --url

- **Type:** `string`
- **Default:** `FLARGS_URL`

The URL of the flags path of a running server.

```sh
# Reads the admin API of this server
npx flargs unset NEW_CHECKOUT --url https://api.example.com/.flags
```

## Output

- **`key`:** the key of the flag.

## Errors

| Error code | Exit code | Condition                                                                                 |
| ---------- | --------- | ----------------------------------------------------------------------------------------- |
| `API`      | 1         | No flag declares the key and no value exists (`404`), or the server has no store (`501`). |
| `API`      | 3         | The token has no `write` access.                                                          |
