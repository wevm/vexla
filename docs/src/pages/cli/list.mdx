# list [Lists every flag of a running server with its value and source]

`flargs list` reads `GET /.flags/manifest`, which needs `read` access. The value and the source are those of the request of the CLI, so they reflect store values, not the overrides of a browser.

```sh
# Lists the flags of the server in FLARGS_URL
npx flargs list --format json
```

## Signature

```sh
# Arguments first, then options
flargs list [options]
```

## Options

### --url

- **Type:** `string`
- **Default:** `FLARGS_URL`

The URL of the flags path of a running server.

```sh
# Reads the admin API of this server
npx flargs list --url https://api.example.com/.flags
```

## Output

- **`flags`:** one entry for each flag, with `key`, `source`, `type`, and `value`.

```json
{ "flags": [{ "key": "PRICING", "source": "store", "type": "select", "value": "b" }] }
```

## Errors

| Error code | Exit code | Condition                                |
| ---------- | --------- | ---------------------------------------- |
| `API`      | 3         | The token has no `read` access.          |
| `NO_URL`   | 1         | Neither `--url` nor `FLARGS_URL` is set. |
