# env [Writes .env.example from the flags file]

`flargs env` writes each flag variable with its default. The description and the type, or the options, precede each variable as comments.

```sh
# Writes .env.example
npx flargs env
```

## Signature

```sh
# Arguments first, then options
flargs env [options]
```

## Options

### --path

- **Type:** `string`
- **Default:** `flags.json`

The path of the flags file, relative to the root.

```sh
# Reads a flags file in another directory
npx flargs env --path config/flags.json
```

### --root

- **Type:** `string`
- **Default:** the working directory

The project root.

```sh
# Runs in the app package of a monorepo
npx flargs env --root apps/web
```

### --out

- **Type:** `string`
- **Default:** `.env.example`

The path of the file, relative to the root.

```sh
# Writes .env.defaults
npx flargs env --out .env.defaults
```

## Output

- **`flags`:** the number of flags.
- **`out`:** the absolute path of the file.

```txt
# Use the new checkout flow.
# Type: boolean.
FEATURE_NEW_CHECKOUT=false

# One of: a, b, c.
FEATURE_PRICING=a
```

## Errors

| Error code      | Exit code | Condition                      |
| --------------- | --------- | ------------------------------ |
| `NO_FLAGS_FILE` | 1         | The flags file does not exist. |
