# stale [Lists flags past their expires date]

`vexla stale` reads the flags file and lists each flag whose `expires` date has passed. A flag is stale from the day after its `expires` date, in UTC.

```sh
# Lists stale flags
npx vexla stale
```

## Signature

```sh
# Arguments first, then options
vexla stale [options]
```

## Options

### --path

- **Type:** `string`
- **Default:** `.env.flags`

The path of the flags file, relative to the root.

```sh
# Reads a flags file in another directory
npx vexla stale --path config/.env.flags
```

### --root

- **Type:** `string`
- **Default:** the working directory

The project root.

```sh
# Runs in the app package of a monorepo
npx vexla stale --root apps/web
```

## Output

- **`stale`:** each stale flag, with `expires` and `key`.

```json
{ "stale": [{ "expires": "2026-01-31", "key": "NEW_CHECKOUT" }] }
```

## Errors

| Error code      | Exit code | Condition                      |
| --------------- | --------- | ------------------------------ |
| `NO_FLAGS_FILE` | 1         | The flags file does not exist. |
