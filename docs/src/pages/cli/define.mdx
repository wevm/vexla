# define [Creates or replaces a flag in the store]

`flargs define` writes a store definition through `PUT /.flags/definitions/:key`, for a project with no flags file. It needs `write` access. [Store Definitions](/guides/store-definitions) describes the setup.

```sh
# Creates a public boolean flag with the default false
npx flargs define NEW_CHECKOUT --type boolean --default false --public
```

## Signature

```sh
# Arguments first, then options
flargs define <key> [options]
```

## Arguments

### key

- **Type:** `string`

Key of the flag, such as `NEW_CHECKOUT`.

## Options

### --url

- **Type:** `string`
- **Default:** `FLARGS_URL`

The URL of the flags path of a running server.

```sh
# Reads the admin API of this server
npx flargs define NEW_CHECKOUT --url https://api.example.com/.flags
```

### --type

- **Type:** `boolean | json | number | select | string`
- **Default:** required

The type of the flag.

```sh
# Creates a select flag
npx flargs define PRICING --type select --default a --options a,b,c
```

### --default

- **Type:** `string`
- **Default:** required

The default value. A boolean, number, or JSON default is JSON text, such as `false`, `3`, or `{"requests":5}`. A string or select default is the text itself.

```sh
# Creates a JSON flag
npx flargs define LIMITS --type json --default '{"requests":5}'
```

### --options

- **Type:** `string`
- **Default:** none

The comma-separated options of a select flag.

```sh
# Three options, with the default a
npx flargs define PRICING --type select --default a --options a,b,c
```

### --public

- **Type:** `boolean`
- **Default:** `false`

Lets the value reach the browser.

```sh
# A public flag
npx flargs define BANNER --type boolean --default false --public
```

### --description

- **Type:** `string`
- **Default:** none

The description of the flag.

```sh
# A flag with a description
npx flargs define BETA --type boolean --default false --description "Beta features."
```

## Output

- **`definition`:** the definition that the server stored.
- **`key`:** the key of the flag.

## Errors

| Error code | Exit code | Condition                                                                                                             |
| ---------- | --------- | --------------------------------------------------------------------------------------------------------------------- |
| `API`      | 1         | The server rejects the definition (`400`), declares its flags in a file (`409`), or has no store definitions (`501`). |
| `API`      | 3         | The token has no `write` access.                                                                                      |
| `NO_URL`   | 1         | Neither `--url` nor `FLARGS_URL` is set.                                                                              |
