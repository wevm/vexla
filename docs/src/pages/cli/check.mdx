# check [Fails when the environment sets an invalid flag value, and reports stale flags]

`vexla check` validates the process environment, and optional dotenv files, against the flags file. A variable that holds a value that is not a value of its flag fails the check. With `--prefix`, an undeclared variable with that prefix also fails, so a typo fails CI. A stale flag fails the check only with `--strict`.

```sh
# Checks the environment and the .env file
npx vexla check --env-file .env
```

## Signature

```sh
# Arguments first, then options
vexla check [options]
```

## Options

### --path

- **Type:** `string`
- **Default:** `.env.flags`

The path of the flags file, relative to the root.

```sh
# Reads a flags file in another directory
npx vexla check --path config/.env.flags
```

### --root

- **Type:** `string`
- **Default:** the working directory

The project root.

```sh
# Runs in the app package of a monorepo
npx vexla check --root apps/web
```

### --env-file

- **Type:** `string[]`
- **Default:** none

Dotenv files to check with the environment, such as `.env`. Repeatable. A file value takes precedence over the process environment.

```sh
# Checks two dotenv files
npx vexla check --env-file .env --env-file .env.local
```

### --prefix

- **Type:** `string`
- **Default:** none

Reports each variable with this prefix that no flag declares, as `unknown`. Without it, the check reports no undeclared variable.

```sh
# Fails on a typo such as FEATURE_NEW_CHEKOUT
npx vexla check --prefix FEATURE_
```

### --strict

- **Type:** `boolean`
- **Default:** `false`

Fails on a stale flag too.

```sh
# Fails when a flag is past its expires date
npx vexla check --strict
```

## Output

- **`issues`:** each problem, with `key` (the variable) and `reason` (`invalid`, `stale`, or `unknown`). A passing check can hold stale issues.

## Errors

| Error code      | Exit code | Condition                                                                                                                                        |
| --------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `CHECK`         | 1         | The environment has an invalid value, an unknown variable with `--prefix`, or a stale flag with `--strict`. The message lists `<key>: <reason>`. |
| `NO_FLAGS_FILE` | 1         | The flags file does not exist.                                                                                                                   |
