# link [Returns a signed link that overrides flags until it expires]

`flargs link` calls `POST /.flags/links`, which needs `write` access and a `secret` on the server. The link overrides runtime flags, including private flags, for each browser that opens it. A build flag is rejected.

```sh
# Returns a link that sets PRICING to c for one week
npx flargs link https://app.example.com/checkout PRICING=c
```

## Signature

```sh
# Arguments first, then options
flargs link <url> <values...> [options]
```

## Arguments

### url

- **Type:** `string`

The page to link, such as `https://app.example.com/checkout`. The `--url` option names the server.

### values

- **Type:** `string[]`

Overrides as `key=value`, such as `PRICING=c`. A boolean, number, or JSON value is JSON text.

## Options

### --url

- **Type:** `string`
- **Default:** `FLARGS_URL`

The URL of the flags path of a running server.

```sh
# Reads the admin API of this server
npx flargs link https://app.example.com/ NEW_CHECKOUT=true --url https://api.example.com/.flags
```

### --expires

- **Type:** `string`
- **Default:** `7d`

The lifetime of the link: a number and `m`, `h`, or `d`.

```sh
# A link that expires in one hour
npx flargs link https://app.example.com/ NEW_CHECKOUT=true --expires 1h
```

## Output

- **`expiresAt`:** the expiry, in milliseconds since the epoch.
- **`url`:** the signed link.

```txt
https://app.example.com/checkout?flag.PRICING=c&flag.exp=1767225600&flag.sig=3q2-7w
```

## Errors

| Error code | Exit code | Condition                                                                                  |
| ---------- | --------- | ------------------------------------------------------------------------------------------ |
| `API`      | 1         | A value is invalid (`400`), a key is unknown (`404`), or the server has no secret (`501`). |
| `API`      | 3         | The token has no `write` access.                                                           |
